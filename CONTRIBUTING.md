# Contributing

Contributions are welcome. Keep source code, commit messages, issues, and documentation in English.

Before opening a pull request:

1. Build against a supported Siemens NX installation.
2. Test destructive commands on disposable copies of representative parts.
3. Run Analyze before and after each repair.
4. Document the NX release and required license modules.
5. Do not commit Siemens binaries, headers, sample parts, or other proprietary files.
