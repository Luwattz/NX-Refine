# 选面扫描停止

去圆角、填孔、清理内腔、去字和修复未贴合面在重新识别候选面时，超过约 0.7 秒会显示“工作进行中 — NX Refine”窗口。单击“停止”、按 Esc 或关闭窗口会请求中断；窗口显示等待提示，扫描在下一个检查点退出。NX 自带工作进度窗口发出的停止信号也会被检查。

取消会清空本轮选择、候选结果和高亮，禁用应用；重新选择实体或承载面即可继续。扫描阶段不提交模型修改。本功能覆盖候选面识别，不覆盖点击“应用”后的删除/修复过程。单次不支持中断的 NX 几何调用必须返回后才能退出；不会强制终止 NX 线程。

## 验证

- `scripts/test-selection-scan.ps1`：独立测试原生停止信号处理、取消状态保持、主线程等待期间按钮响应、关闭窗口和重新开始。
- NX 内人工回归：分别打开五种工具，选择大型模型，扫描期间点击停止；确认候选列表/高亮清空、应用不可用、模型未改动；重新选择并成功完成识别。
- 还应覆盖参数修改触发重新扫描、Esc/关闭停止窗口、连续快速选择、正常完成自动关闭进度窗口，以及 NX 自带停止信号。

独立测试不替代真实 NX 模型中的交互验证。
